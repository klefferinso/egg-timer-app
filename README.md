# 🥚 Egg Timer App

A React Native iOS app that helps you cook the perfect egg every time.

## Features
- 4 egg types: Hard Boiled, Soft Boiled, Sunny Side Up, and Scrambled
- Countdown timer with animated circular progress ring
- Bell sound when timer finishes
- Custom icons and warm creamy UI
- Built with Expo and React Native

## Tech Stack
- React Native
- Expo (SDK 54)
- expo-router (navigation)
- expo-av (sound)
- react-native-svg (progress ring)
- @expo-google-fonts/nunito & fraunces (custom fonts)

## Screens
- **Welcome Screen** — Select your egg type
- **Timer Screen** — Countdown with animated progress ring
- **Done Screen** — Notification when egg is ready

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `npx expo start --go`
4. Scan the QR code with your iPhone
